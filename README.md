# 35-Maktab — premium maktab profili

Manzil: RP9V+9R, Qarshi, Qashqadaryo Region, Uzbekistan.

## Sayt tuzilishi
- `index.html` — bosh profil sahifasi: umumiy ma’lumot, qisqa kartalar, maktab haqida, bo‘limlar, ish vaqti, manzil va aloqa.
- Alohida sahifalar: `maktab-haqida.html`, `rahbariyat.html`, `oquv-jarayoni.html`, `yutuqlar.html`, `elonlar.html`, `togaraklar.html`, `fotogalereya.html`.
- `style.css`, `script.js`, `assets/favicon.svg`.
- `robots.txt`, `sitemap.xml` — qidiruv tizimlari uchun boshlang‘ich fayllar.

## Kompyuterda ko‘rish
`index.html` faylini brauzerda oching. Internetga joylashda barcha fayllarni bir papkaga yuklang.

## GitHub Pages
1. GitHub’da Public repository yarating.
2. ZIP ichidagi barcha fayllarni repository root-ga yuklang.
3. Settings → Pages → Deploy from a branch → `main` va `/(root)` → Save.
4. Sayt `https://USERNAME.github.io/REPOSITORY/` manzilida ishlaydi.

## Muhim
E-mail, direktor, o‘qituvchilar, ish vaqti, aniq koordinatalar, statistika va yutuqlar tasdiqlanmagan. Bog‘lanish telefoni foydalanuvchi bergan raqam bilan to‘ldirilgan. Sayt ularni uydirmaydi; maktab tasdiqlagan ma’lumotlar bilan to‘ldiring. `sitemap.xml` ichidagi `YOUR-DOMAIN.uz` ni haqiqiy domen bilan almashtiring. Google indekslashi kafolatlanmaydi va vaqt olishi mumkin.


## Interaktiv xarita
Bosh sahifadagi manzil bo‘limiga Google Maps qidiruv xaritasi qo‘shilgan. Qidiruv manzili: 35-sonli umumiy o‘rta ta’lim maktabi, Batosh MFY, Qarshi tumani, Qashqadaryo. Qo‘shimcha ravishda Yandex Maps’dagi “Школа № 35” Batosh mikrohududi yozuvi havola qilingan.
Eslatma: ochiq xarita kataloglarida maktabning aniq koordinatasi bir xil ko‘rsatilmagan. Shu sabab xarita qidiruv natijasini ko‘rsatadi; maktabning aniq kirish joyi ekanini ma’muriyat bilan tasdiqlash kerak.
